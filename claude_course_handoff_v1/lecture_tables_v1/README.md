# Concise coloured lecture tables

Twelve reusable inserts accompanying the frozen evidence pack. These are concise summaries, not a lecture sequence or new experiments.

## Open and reuse

- [Browse the tables](index.html): selectable text, local evidence links and individual asset links.
- [Printable PDF](output/pdf/lecture_tables.pdf): one table per landscape A4 page.
- `svg/`: vector tables for scaling or editing in design tools.
- `png/`: high-resolution cropped tables for pasting into lecture notes, Word or slides.
- [Editable content](tables.json): the shared text and colour-label definitions.
- [Evidence references](SOURCES.md): table-specific sources in the existing evidence pack.

Keep the qualification underneath each table when reusing it. PASS is scoped to retained checks, not universal correctness. Colour is always accompanied by text: green = validated; amber = qualified/incomplete; red = wrong/invalid; blue = descriptive observation; grey = not produced. Blue is not a strength rating.
