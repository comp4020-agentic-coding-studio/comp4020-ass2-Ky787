All 21 binaries are exact retained Windows AMD64 PE files. No programs were run during curation. Static inspection and reading work on Linux with a suitable disassembler; execution/x64dbg requires a separately supplied Windows x64 environment. No Wine compatibility is claimed. All filenames are preserved from the selected source location. Repeated `showcase.exe` names are separated by descriptive directories.

No PDB or MAP is packaged: use exported function names or loaded module base + RVA. This is intentional portability/size curation. For every rewrite, decline automatic loading of original PDBs: old RSDS identifiers may survive while internal mappings are stale. Runtime PASS does not establish exhaustive exception/unwind correctness.
