## An injected gate

```asm
140001640: mov eax, dword ptr [rip + 0x879d6]
140001646: mov ecx, dword ptr [rip + 0x879cc]
...
140001667: jne 0x140001672
```

Two writable globals. A predicate over them. A conditional jump.

Nothing about this says which way it goes.

---

## The obligation, written down

Path prefix `P`, branch condition `C`:

```text
P ∧ C      is this direction reachable?
P ∧ ¬C     is the other one?
```

Two queries. Three possible answers each: SAT, UNSAT, UNKNOWN.

---

## What the solver returned

```json
"branch_rva": "0x1667",
"queries": {
  "true":  { "status": "SAT",
             "model": { "g_140089018_4": 0,
                        "g_14008901c_4": 0 } },
  "false": { "status": "UNSAT", "model": {} }
}
```

One direction has a model. The other has none.

```notes
- SAT gives you a witness. UNSAT gives you the absence of one, in scope
- 46 AST nodes, 2 symbolic variables, 3 ms
```

---

## Read the qualifier twice

> Under path prefix `P`, UNSAT for `P ∧ ¬C` rules out that direction **for
> states covered by `P` and by the model.**

Not: "this branch is opaque."

```notes
- a path-local UNSAT is not a global invariant
- inconsistent assumptions make a proof vacuous, not strong
```

## From proof to bytes

```text
before   0F 85 05 00 00 00     jne 0x140001672
after    E9 06 00 00 00 90     jmp 0x140001672 ; nop
```

Six bytes. Four of them differ. The destination is unchanged — a shorter
opcode needs a longer displacement.

22 gates × 4 differing bytes = **88 bytes changed** in a 571,904-byte file.

---

## What the rewrite did and did not do

- reachable blocks: **70 → 37**
- physical blocks: **70**
- 33 original blocks now unreachable: 11 clones, 22 stubs
- predicate arithmetic: **still there**
- headers, sections, exports, unwind ranges: **identical**

Not a clean binary. A working partial deobfuscation.

---

## And then it was tested

- **4,591** clean / original / rewrite triples
- **0** mismatches
- canonical run: `SHOWCASE PASS`, exit 0

Plus 4,598 more on the second implementation.

```notes
- 9,189 triples total. Which is a lot of inputs and not all inputs
```

---

## Four achievements, kept apart

1. a solver returned UNSAT, under a stated prefix and model
2. separate code turned that into changed bytes
3. the file still loads and exports the same symbols
4. the program answered correctly on the inputs that were run

**1 does not imply 4.**
